# SubBurn Support

SubBurn is made by **Anas Al Hwaity**.

For owner contact and project questions:

- Telegram: [@ANAS12RM](https://t.me/ANAS12RM)

For reproducible bugs, prefer a GitHub issue and include:

- operating system and version;
- SubBurn source/release identifier;
- complete Activity log around the failure;
- selected codec/encoder/quality settings;
- whether the problem occurred in Tkinter, the browser dashboard, or both;
- a screenshot when the issue is visual or progress-reporting related;
- whether the issue reproduces after a clean restart.

Do not post private media, private subtitle content, access tokens, passwords, or personal filesystem data that is unrelated to the bug.
